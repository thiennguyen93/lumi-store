Keys this page cannot hear
  • fn / Globe, Touch ID and the power key never reach a web page, so they stay grey.
  • F1–F12 control brightness, volume and media by default. Hold fn while pressing them to test them as keys.
  • Caps Lock as Lumi's Hyper key is never heard on its own. Hold it and press a key none of your Hyper shortcuts use: the modifiers it adds are how this page knows it works.
  • Shortcuts macOS or Lumi take first — ⌘Tab, ⌘Space, ⌘Q, a shortcut you recorded in Lumi — are used up before they get here. Test those keys on their own.
