Keys this page cannot hear
  • fn / Globe on its own is heard through Lumi, which needs its Accessibility permission. If pressing it alone does nothing, hold it and press delete or an arrow: those make keys a MacBook does not have, which is how this page knows fn works either way.
  • Touch ID and the power key never reach a web page, so they stay grey.
  • F1–F12 control brightness, volume and media by default. Hold fn while pressing them to test them as keys. Lumi keeps macOS from taking them while this tab is in front, so F11 tests here instead of showing the desktop. While cleaning, they light up without fn too.
  • Caps Lock as Lumi's Hyper key is never heard as itself. Tap it on its own if the tap toggles Caps Lock, or hold it and press a key none of your Hyper shortcuts use — either tells this page it works.
  • Shortcuts macOS or Lumi take first — ⌘Tab, ⌘Space, ⌘Q, a shortcut you recorded in Lumi — are used up before they get here. Test those keys on their own, or while cleaning, when nothing takes them.
While cleaning
  • Clean keyboard locks every key right away, for as long as the Settings tab says — and the trackpad too, if you turned that on there.
  • Every key is held, in every app: letters, ⌘Tab, Spotlight, brightness, volume and media. Lumi's own shortcuts and snippets rest too.
  • Three ways out: hold the button here, hold esc and right shift together, or wait for the time to run out. If this page stops answering, Lumi lets go itself after 5 seconds of the same two keys.
  • Touch ID and the power key can't be held. A press locks your Mac, which ends cleaning.
  • Another app's password field can keep the keyboard to itself; cleaning can't start until it lets go.
