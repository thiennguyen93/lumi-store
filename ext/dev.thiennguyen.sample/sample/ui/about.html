Reference extension

One of everything, small enough to read.

Sample exists so an extension developer can see every surface Lumi offers working at once, in a package short enough to read end to end.

  • A command Translate selection reads what you selected and opens it in Google Translate.
  • A flow node Shout upper-cases each item's text — pure compute, no capability needed.
  • A window Sample settings talks to the extension's own WebAssembly through the bridge.
